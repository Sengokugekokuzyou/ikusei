# Windows かんたん手順（コマンドが苦手でもOK）

VOICEVOX（デスクトップ版）で **声つきの動画** を作るための、クリック中心の手順です。

---

## 用意するもの（初回だけ）

### 1. VOICEVOX を起動しておく
デスクトップ版 VOICEVOX を立ち上げておくだけでOK（もう起動済みならそのまま）。
起動していれば裏で `http://127.0.0.1:50021` が動き、声が使えます。

### 2. Python を入れる（入っていなければ）
1. https://www.python.org/downloads/ を開く
2. 黄色い「Download Python」ボタンでインストーラを取得
3. インストーラを実行し、最初の画面の **「Add python.exe to PATH」に必ずチェック** → Install Now
4. 終わったら閉じる

> すでに Python が入っているか分からなくてもOK。入っていなければ、下のバッチが「入れてね」と教えてくれます。

### 3. このプロジェクトをダウンロード
1. GitHub のこのリポジトリのページを開く
2. ブランチを `claude/ai-navigator-youtube-automation-2xsygi`（またはマージ後は `main`）に切り替え
3. 緑色の **「Code」** ボタン → **「Download ZIP」**
4. ダウンロードした ZIP を右クリック → **「すべて展開」** で解凍

---

## 動画をつくる（毎回これだけ）

1. VOICEVOX が起動していることを確認（声を入れたい場合）
2. 解凍したフォルダの中の **`scripts` フォルダ** を開く
3. **`make_video.bat` をダブルクリック**
4. 黒い画面が出たら、動画のテーマを入力して **Enter**
   （何も入れずに Enter すると「Claude Code vs Codex」で作ります）
5. 数分待つと、できあがった **`video.mp4`** が自動で開きます

> できた動画は、プロジェクト内の `reports\（日付）_（テーマ）\video.mp4` にも保存されています。

---

## 最新版に更新するとき（GitHub操作なしでOK）

2回目以降のアップデートは、GitHubからZIPを取り直す必要はありません。

1. `scripts` フォルダの **`update.bat` をダブルクリック**
2. 「Update complete」と出たら完了
3. あとはいつも通り `make_video.bat` をダブルクリック

（あなたが作った動画＝`reports` フォルダ、用意した画像＝`assets` フォルダは消えません）

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「Python が見つかりません」と出る | 上の「2. Python を入れる」を、**PATH のチェックを入れて**やり直す |
| 声が入らない（無音） | VOICEVOX を起動してから、もう一度ダブルクリック |
| 声を別のキャラにしたい | `make_video.bat` の `--speaker 3` の数字を変える（`3`=ずんだもん）。番号は VOICEVOX アプリのキャラ一覧、または詳しい人向けに `py -m ai_navigator speakers` で確認できます |
| 黒い画面が一瞬で消える | `make_video.bat` を右クリック→編集 で中身が壊れていないか確認、または管理者権限で実行 |

困ったら、黒い画面に出たメッセージをそのままコピーして聞いてください。
