# assets/ — 人が用意する画像を置く場所（§48/§49/§70）

ここに画像を置くと、動画の該当シーンの**背景**に使われます。**公式スクショ・公式X投稿・ロゴなど、あなたが権利や引用要件を判断した画像**を安全に使うための場所です（自動取得のB-rollとは別）。

## 使い方

- `scene_<番号>.jpg`（または `.png` / `.webp`）を置く → その番号のシーン背景に使われる
  - 例: `scene_1.jpg`（オープニング）、`scene_5.jpg`（比較の周辺）
  - シーン番号は `reports/<日付>_<テーマ>/storyboard.json` の `scene_id`、または `video.mp4` を見て決める
- 同じ番号で `scene_<番号>.txt` を置くと、その1行目が**画面右下の出典キャプション**になります
  - 例: `scene_5.txt` の中身 → `出典: OpenAI 公式発表 https://openai.com/index/introducing-codex/`
  - これで日本の著作権法§32「引用」の**出典明示**要件を満たせます（公式発表・公式Xの引用に）

## 注意（収益化の安全）

- **公式発表・公式X・スクショ**は「**出典つきで引用**」の形で（解説・比較の文脈）。装飾目的の無断転載はNG
- **架空UIを本物のように見せない**（§49）。本物のスクショだけを使う
- 一般的なB-roll（人物・オフィス等）は `images` コマンドで Pixabay / Openverse から自動取得できます（`python -m ai_navigator images --plan ... --provider openverse`）

このフォルダに置いたあなたの画像は Git に含めません（`.gitignore` 済み）。
